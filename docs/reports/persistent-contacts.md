# Постоянные контакты: как это сделано в других движках и что менять у нас

Прочитано 2026-11-20 по исходникам из `research/refs` (Box3D, Jolt, Bullet, ReactPhysics3D, PhysX). Вопрос один:
как контакт переживает шаг без нового поиска площадки и какое событие заставляет искать её заново. Код
оттуда не копируется; ниже только устройство и числа.

## 2. Общее у тех, кто пропускает поиск

1. Между шагами живёт **площадка вместе с импульсами**: точки в осях тел, нормаль, нормальный импульс каждой
   точки, трение на площадку. Строки решателя (массы, плечи в мире) собираются из неё заново раз в шаг.
2. Событие для нового поиска — **сдвиг пары относительно позы последнего полного поиска**: порог на
   перенос и порог на поворот. Пока контакт едет за телами, опорная поза не обновляется, поэтому ошибка
   не накапливается сверх порога.
3. Пока порог не превышен, состав точек и импульсы не трогаются; пересчитывается только зазор.
4. Упреждающий запас у всех около 20 мм: точка входит в площадку до касания.
5. Импульсы пишутся обратно в запись один раз, в конце шага.

## 3. О чём авторы предупреждают сами

- **Bullet** выключил пропуск узкой фазы по оценке расстояния: при большом отношении размеров GJK неточен, и
  столкновения пропускались (`btConvexConvexAlgorithm.h:31`). Нормаль, которая хранится в мире и не
  поворачивается, даёт ошибку, как только тело повернулось.
- **PhysX**: допуски, растущие с размером формы, выбрасывают контакты большой формы с мелкими треугольниками —
  для сеток запас взят меньше. «После обновления точек часть контактов может потеряться» — тогда полный поиск.
- **Jolt** держит запас глубины 20 мм, чтобы контакт не мигал «есть — нет»: миганье стирает кэш.
- **Box3D** выключает пропуск для быстрых тел (путь за шаг больше половины наименьшего размера): вокруг ребра
  тело может провернуться, и сохранённые признаки устаревают. Про сам пропуск: «это убирает дрожь».

## 4. Что уже есть у нас и чего нет

| | У нас | Вывод |
|---|---|---|
| опорная поза пары на момент поиска, порог на сдвиг с дугой поворота | есть (`ManifoldMemory::Entry::apart`, `valid`) | устройство то же, что у Box3D и PhysX |
| нормаль и точки в осях тел | есть: нормаль — в осях тела с опорной гранью | лучше, чем у Box3D и Bullet |
| номера точек | есть | перенос импульсов по номеру, как у Box3D |
| трение одной величиной на пару | есть (`SoftContact::rub_`, `twistImpulse_`) | так же |
| импульсы в записи площадки | **нет**: отдельная память `ContactForces`, переписывается целиком каждое обновление | перенести |
| контакт едет за телами, пока порог не превышен | **только геометрия**; контакт решателя строится заново каждое обновление, до четырёх раз за кадр | строить по событию |
| пары только для сдвинувшихся тел | **нет**: все тела, каждое обновление | раздутый объём и список сдвинувшихся |
| допуск | 0,2 мм | в 5 раз строже Jolt, в 250 — Box3D; менять только замером |

## 5. Порядок работ

Каждый шаг — с прогнозом в журнале попыток и теми же воротами: хэш у двух компиляторов и при 1, 4, 12 потоках,
табло, стандартные сцены, разброс перекрытия в сценах с ударами.

1. **Пара с годной площадкой не перестраивается внутри кадра.** На втором–четвёртом обновлении контакт
   решателя такой пары остаётся и только переопирается на нынешние позы; заново строятся пары, у которых
   наступило событие (сдвиг за допуск, появление). Мерка: пирамида 1 015 кубов с падающим рядом шаром —
   стадия «контакты» 14,8 → не больше 8 мс.
2. **Импульсы — в запись площадки**, в память сил они пишутся раз в кадр (её читают точный шаг и сон). Мерка:
   стадия «память» в той же сцене 3,9 → не больше 1,5 мс.
3. **Поиск пар только для сдвинувшихся тел**: раздутый объём тела, как у Box3D и ReactPhysics3D. Мерка: стадия
   «пары» в покое 5,7 → не больше 2 мс.
4. **Допуск**: проба 1 мм (Jolt) и доли размера формы (PhysX) на всех воротах; принять только без потери в
   сценах с ударами.

Чего не переносим: мировую нормаль без поворота (Bullet, Box3D при пропуске) — у нас нормаль в осях тела;
перенос импульсов по расстоянию — у нас есть номера точек; множитель 0,85 на тёплый старт (Bullet).
