# Проверка сборки контактных матриц

Границы опыта задаются до запуска. Одна гипотеза меняет хранение списка «тело → номера строк», вторая резервирует рабочие массивы по числу активных строк. Физические формулы, порядок суммирования, точность, бюджеты решателя и режим сна одинаковы.

| Инвариант | Измерение | Критерий |
|---|---|---|
| Матрица сохраняет порядок строки и вклады обоих тел | Численный вывод 36 захватов. Для кандидата на включение также 17 физических наборов и контрольные хэши | Побайтное совпадение с исходной сборкой |
| Улучшение заметно в полном кадре на одном процессоре | Отношение времён кандидата и исходной сборки внутри 24 сбалансированных блоков | Для переноса в ядро медиана ≤ 0,98 в захвате, не менее 18/24 выигрышей и медиана ≤ 1,02 на пирамиде |
| Временное хранение не растёт как квадрат числа тел | Анализ числа элементов временного индекса до вычисления откликов | Число индексов строк ≤ 2L для L строк, служебные таблицы растут линейно по телам. Выходная матрица учитывается отдельно |

Сцены для проверки контрпримеров охватывают пустой набор активных строк, две строки через одну и ту же пару тел и несколько тел с общей неподвижной опорой. Фактические проверки и решение о включении записываются в основном отчёте.
