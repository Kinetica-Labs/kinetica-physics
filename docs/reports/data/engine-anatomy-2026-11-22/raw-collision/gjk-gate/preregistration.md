# GJK selective fallback — preregistration

Inputs are the same saved rounded-core GJK baseline and wide oriented-area projection used in gjk-weights. Do not change geometry or oracle thresholds. A complete pass of the wide algorithm can be skipped if the original separated core result is supported along its own reported direction.

- U = |v| for the final closest point of the original Minkowski simplex, L = dot(v, support(-v))/U. Both bounds in metres refer to uninflated ORIGINAL cores. Subtraction of both rounding radii preserves U−L even for overlapping rounded surfaces whose cores are distinct. For a cylinder shrink the bounds instead refer to another shape. Never rank a shrunk result as if it were on the original geometries.
- Accept stock if U and L are finite and |U−L| <= tau, where tau = max(1e−9 m, 64 epsilon * max(RA,RB,U)). The 1 nm length is the SDK kOnBoundary/kBeyondMargin, the factor 64 is the existing GJK relative progress threshold. No threshold from the 2e−7 m witness oracle, source cases, or holdout. This is a floating-point diagnostic envelope, not an end-to-end certified arithmetic proof. Width bounds core distance; it does not bound witness coordinates individually.
- A stock beyond result or unresolved core overlap is returned as-is. A valid analytic point-core path is returned as-is. Infinite positive query horizon stays unbounded and never enters the scale. A non-finite baseline with unusable witnesses stays baseline; unresolved wide/beyond/shrunk results cannot replace a resolved stock answer. If the first resolved answer used a shrink, retry and only accept a finite supported unshrunk alternative. Otherwise choose the smaller nonnegative interval width among same-geometry finite answers, reject certificates L>U+tau; ties stay stock.
- Cache the already queried final support dot at a normal exit (dual, duplicate, or plateau: v unchanged). Only a descent that advances on iteration 64 needs a new pair of supports to obtain a bound for that final v. Compute the division only for a resolved result. Count base and retry descent support calls, new support calls exclusively for the certificate, point-core probes, and queries of shape bounds separately. Compare actual support costs also to always making both descents.
- Before looking at native holdout, freeze this rule. Acceptance: positives vs stock on both 1440-row probes with no new failed predicate vs always-two on those previously passing, no regressions in baseline public contracts incl overlap/beyond/analytic and no routine second descent on every case. Report raw counts and disagreements even if the target fails. Do not infer timings from support counts.
