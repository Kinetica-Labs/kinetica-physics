# Парное сравнение на пороговом захвате

До прогона фиксируем опытную сборку с размерами оболочки, резервированием строк и пропуском точно нулевых импульсов (`guide-work/combined.exe`). У предыдущего прототипа она выиграла 23 из 24 пар в каждой из двух уже завершённых серий. Контроль — исполняемый файл с SHA-256 `e87852abfca6acca4fac6acf95fe5cb0dfda7daa7aa29aa1d01eef0d67b82fc4`. Соперники — RP3D double, Box3D float и Bullet double с 8 итерациями. В опыт не входит показавшая замедление замена сил площадки равнодействующей.

1. Вход каждого таймера — один и тот же нагруженный захват при 60 Гц, 1 кг, 10 Н прижима каждой губки, 10 Н внешней нагрузки и трении 0,5. Выход — среднее время 360 полных кадров в микросекундах. Восемь активных публичных шагов на кадр, один поток, привязка к одному процессору, сон выключен.
2. Удержание должно укладываться в 0,5 мм, ошибка реакции каждой губки — в 0,2 Н. Сравнение времени при заданной точности допускается только после выполнения этого условия обеими сборками. В сетке из 36 входов скольжение дополнительно проверяется по аналитической траектории с допуском 2 мм. Сетка задана заранее и исчерпывающе перечислена для этой задачи.
3. Собираем 40 блоков без досрочной остановки, в каждом перемешиваем пять программ заново с семенем 2026112307. Основное сравнение — новая Kinetica с RP3D, единица наблюдения — полный блок. Для времени показываем медиану по блокам, парную разницу в мкс, отношение времён и непараметрический интервал медианы парного отношения через порядковые статистики. Для частоты строгих побед — двусторонний 95%-й интервал Уилсона. В точном двустороннем тесте знаков равенства исключаются. Для четырёх сравнений учитываем множественность по Холму. Отдельно считаем блоки в бюджете 50 мкс. Серийную зависимость оцениваем чувствительностью вывода к группировке по пяти соседним блокам. Диапазон вывода ограничен одной сценой и одним ПК.
