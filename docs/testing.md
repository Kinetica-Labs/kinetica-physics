# Как проверяется физика

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

Для примеров и модульных проверок достаточно C++17. Python 3.9+ добавляет проверку полной таблицы контактов и сертификаты движения. На Unix CTest также подключает установленные Z3 и Why3. [Состав проверок](../tests/CMakeLists.txt) · [Регрессионные сцены](../tests/regression/CMakeLists.txt)

| Что измеряется | Критерий |
|---|---|
| Ошибка движения | Аналитический ответ задаёт физическую величину и допуск. Например, для шестерён сравниваются углы в радианах и скорости в рад/с. [Учебный пример](../examples/05_world/GearTrain.cpp) |
| Повторяемость | После 60 кадров позы и импульсы всех тел дают 52 контрольные строки. Каждая строка сравнивается с эталоном. [Расчёт](../tests/regression/StateHash.cpp) · [Эталон](../tests/data/state-hash.txt) |
| Контакт | Для 7 425 комбинаций формы, признака, относительного размера и режима выполняются четыре пробы. Принимается только полная сетка, а число нарушений каждой метрики ограничено. [Прибор](../tests/regression/CaseTable.cpp) · [Критерии](../tests/regression/case_table.py) · [Пределы](../tests/data/case-table-counts.json) |
| Формальные свойства | Для лемм о контактах проверяются вывод и совместность посылок. Для известного контрпримера решатель должен найти допустимое состояние. [Модели и проверки](../tests/proofs) |

Эталон повторяемости получен из 52 совпавших строк Clang на Windows и GCC в WSL для исходников этой версии. Совпадение хэша отвечает на вопрос о повторяемости. Для точности захвата отдельно измеряется смещение куба относительно губок в миллиметрах.
