# Исследование чужих движков

Чем отличаются MuJoCo, Box3D, Jolt, Rapier, PhysX, Bepu и Bullet — по исходникам, со ссылкой на строку кода у каждого
утверждения. Из этого исследования выведены решения в `docs/DEVELOPMENT.md`. Пути ниже — от этого каталога.


| Путь | Что там |
|---|---|
| `engines/` | карточка на движок по `engines/_TEMPLATE.md` — связный разбор |
| `data/facts/<engine>.jsonl` | те же сведения атомами: один факт — одна строка со свидетельством |
| `data/schema.jsonl` | оси, ключи и словарь допустимых значений |
| `data/sources.jsonl` | закреплённые коммиты клонов |
| `tables/` | сводные таблицы — генерируются, руками не правятся |
| `refs/` | клоны `--depth 1`, вне git; восстановить: `facts.py restore` |
| `facts.py` | проверка фактов, выборка для перепроверки, генерация таблиц |

## Правила фактов

Строка `data/facts/<engine>.jsonl`:

```json
{"engine":"box3d","axis":"solver","key":"family","value":["soft-step"],
 "note":"одно предложение: что именно и с какой оговоркой",
 "evidence":[{"kind":"src","ref":"box3d","path":"src/solver.c","lines":[210,260],"quote":"b3SolveContact"}],
 "date":"2026-11-14"}
```

- `axis`, `key` — только из `data/schema.jsonl`. Если у ключа есть `enum`, значение берётся из него;
  если `multi` — значение список.
- Факт без свидетельства не существует. Виды свидетельств:
  - `src` — прочитан код клона: `ref`, `path`, `lines:[a,b]` (не шире 60 строк) и `quote` —
    короткий дословный фрагмент, который стоит в этих строках. `facts.py check` это проверяет.
  - `prior` — то же, но `ref: "phys_realflow"` (ранее сделанный разбор).
  - `absence` — «этого в движке нет»: `ref`, `pattern` (регулярное выражение для `rg -i`),
    необязательный `path`; проверка требует нуля совпадений.
  - `doc`, `paper`, `talk`, `secondary` — `url` обязателен. `secondary` (чужой пересказ) —
    только когда первичного источника нет.
- Файлы дописываются, не переписываются: исправление — новая строка с тем же
  `(engine, axis, key)`, действует последняя.
- Не удалось установить — факта нет, а ключ назван в разделе «Не выяснено» карточки.

## Команды

```
python3 facts.py check [engine]     схема, словарь, свидетельства
python3 facts.py sample <engine> 10 случайные факты с процитированными строками — для перепроверки
python3 facts.py tables             tables/matrix.md
```
